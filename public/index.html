Vercel Cron · OpenRouter · Image worker

LinkedIn Auto Poster

Once a day Vercel calls /api/cron. That run writes a post with the OpenRouter model, renders the matching illustration through your image endpoint, then publishes both to LinkedIn.

1. Connect LinkedIn

Authorises your member account and prints the env values the cron job needs.

Connect LinkedIn

Needs the Share on LinkedIn product (scope w_member_social) and Sign In with LinkedIn using OpenID Connect on your LinkedIn app.

2. Test without publishing

Generates the text and image, then stops before touching LinkedIn.

curl -H "Authorization: Bearer $CRON_SECRET" \
  "$PUBLIC_BASE_URL/api/cron?dry=1"

3. Let the schedule run

The schedule lives in vercel.json:

"crons": [{ "path": "/api/cron", "schedule": "0 9 * * *" }]

Hobby plans only allow one cron run per day. Vercel sends Authorization: Bearer $CRON_SECRET automatically when that variable exists.

Environment variables

NameWhat it is
CRON_SECRETLong random string; guards /api/cron.
OPENROUTER_API_KEYKey for the text model.
OPENROUTER_MODELModel slug, e.g. google/gemini-2.5-flash.
IMAGE_API_URLYour image worker URL (the one from automation.py).
IMAGE_API_KEYBearer key for that worker.
LINKEDIN_CLIENT_IDFrom the LinkedIn app.
LINKEDIN_CLIENT_SECRETFrom the LinkedIn app.
LINKEDIN_REFRESH_TOKENPrinted by the connect flow (preferred).
LINKEDIN_ACCESS_TOKENFallback when no refresh token is issued.
LINKEDIN_PERSON_URNurn:li:person:…, saves a lookup per run.
LINKEDIN_API_VERSIONVersioned API release, e.g. 202510.
POST_TOPIC, POST_TONE, POST_AUDIENCEOptional writing controls.
PUBLIC_BASE_URLOptional, e.g. https://your-app.vercel.app.
LINKEDIN_REDIRECT_URIOptional exact callback URL override.
